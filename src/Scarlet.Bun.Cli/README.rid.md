# Scarlet.Bun.Cli.*

This package is a per-platform implementation detail of
[`Scarlet.Bun.Cli`](https://www.nuget.org/packages/Scarlet.Bun.Cli/), restored automatically for you by
`dotnet tool install`/`dotnet tool restore`. It carries no library assets, so `dotnet add package` on it
installs nothing usable.

Install `Scarlet.Bun.Cli` instead:

```bash
dotnet tool install --global Scarlet.Bun.Cli
```

See [`Scarlet.Bun.Cli`](https://www.nuget.org/packages/Scarlet.Bun.Cli/) for full documentation.
