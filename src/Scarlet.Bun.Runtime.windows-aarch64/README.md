# Scarlet.Bun.Runtime.windows-aarch64

This package contains the Bun runtime for Windows ARM64.

`Scarlet.Bun.MSBuild` does **not** depend on this package directly.
Install it only if you want to provide a pre-packaged Bun runtime — `Scarlet.Bun.MSBuild` will discover it automatically when present.

The package version corresponds to the bundled Bun version (e.g., package version `1.3.12` contains Bun `1.3.12`).
